建站小记 ~

向往之事 初中，那时候的我还是一个末流 OIer，经常在学校机房写代码，常用的 OJ 就是洛谷。 为什么是洛谷？不会写题的话还可以看题解，题解都看不懂时可以看各种云剪贴板中的小故事，还是很快乐的时光呢。以及，洛谷的个人主页是可以高度自定义的，可以去网上搜各种插件，然后装点门面（云剪贴板同理），实际上这个时候就已经有了点博客平台的样子呢。 洛谷可以说是我 ACGN 的一大启蒙了呢，这个之后有时间再写文章讲下吧~ 除了洛谷上的博客，网上搜东西，免不了看其他平台的博客，像是 CSDN、博客园之类的。但众所周知，这两个平台的内容质量一言难尽——虽然有很多优质内容，但多被抄袭注水的内容覆盖。有时候想要搜一个东西，翻开第一篇，试了下，没用，然后看下一个、下下个，以此类推，然后你可能会惊奇地发现——内容都差不多，然后你一个下午就这么过去了。 再者，CSDN 中“登录后复制代码”（都是程序员了，谁不会按F12查看源码啊）、“付费下载资源”（GitHub 上的免费软件拿来挂，实在不太厚道）之类的问题，对新人也不太友好。不得不感叹，国内的博客平台，环境是真的差。 这时候，看到几个炫酷的个人网站，里边有高质量的内容，还是非常让人眼前一亮的吧？后续搜东西就都认准那些个人或者小团队建设的小站，体验就好多了呢~ 也就这个时候，有了对“建立自己的网站”的向往吧？ 追忆未曾见过的黄金年代 实际上，在 2000 年左右，建立一个自己的网页，也是一种风潮呢。运用像是 FrontPage 之类的软件，就可以像编辑 Word 一样写网页，使得建站的门槛大大降低，即使是电脑小白，也能轻松写一个自己的“网络名片”呢。 不过，随着各种中心化平台的出现，以及网页的复杂化，门户网站的时代一闪而过，建站的门槛也越来越高。或许有人反驳，现在肯定有更简单的方案啊，技术总归是在进步的呢！但是，在意识层面，网站已经变成了“高大上的、难以接触的东西”，而不是“像 Office 三件套一样的东西”了。再者，有那么多写东西的平台，为何非要自己搓一个呢？ 接上一句话，既然平台不作为，为什么不自己搭一个呢？ 是的，就是有那么多人，搞出了多种多样的开源方案呢。虽然未见过黄金年代的荣光，但那时的余辉，又似乎处处闪耀。 青涩的尝试 高一时，从洛谷一篇博客中了解到 Gridea + GitHub Pages 这种超级简单的方案。虽然很多东西都不懂，但是照着文章一步步抄作业，也是第一次建立了自己的博客站呢。 不得不说 Gridea 确实是个非常纯粹、易用的方案，你真的可以像使用 Typora 那样的 Markdown 编辑器一样写文章，然后同步发布。如今如果有人想要建博客站的话，我依旧首先推荐 Gridea Pro，除了同步到 GitHub 时看脸，其他没有明显缺点。 这个小站的用途，早期是用于发各种牢骚吧？（根本没有定力认真写东西） 后来在上边同步发布我的随笔。本来想着这样语文老师的随笔作业就不用交了，结果最后老师告诉我网站上不去。哎，GitHub 的老问题了，也就只好作罢。 唯一还算有意义的文章还是ACGN资源站一览，不过在那以后对于这个网站也是半遗忘状态了。 现在这个站点，作为黑历史，可以通过本站的友链访问哦~ 小站缘起 本站最早可以追溯到我高三的时候，折腾了一天的新站项目吧。（旧站的确有点不堪回首啊） 当时是直接照着 B 站上一个 UP 主的方案抄作业，用的也是 Hugo + GitHub Pages 的方案。整完之后就懒得动了，后来也删库了。 不过，突然又回想起了这个东西，于是就重新弄起来啦。 伪Vibe Coding 高三刚开始我还很排斥使用各种 AI 工具，坚持古法使用搜索引擎。当然啦，从一大堆广告、抄袭、山寨、钓鱼网页中找到官网或者清晰明了的文档真的很有成就感的好吧？不过自从尝试把 AI 用作搜索引擎之后，就一发不可收拾，即刻沦陷。 ...
