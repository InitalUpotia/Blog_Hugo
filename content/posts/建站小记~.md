## 向往之事

初中，那时候的我还是一个末流 OIer，经常在学校机房写代码，常用的 OJ 就是[洛谷](https://www.luogu.com.cn/)。

为什么是洛谷？不会写题的话还可以看题解，题解都看不懂时可以看各种云剪贴板中的小故事，还是很快乐的时光呢。以及，洛谷的个人主页是可以高度自定义的，可以去网上搜各种插件，然后装点门面（云剪贴板同理），实际上这个时候就已经有了点博客平台的样子呢。

洛谷可以说是我 ACGN 的一大启蒙了呢，这个之后有时间再写文章讲下吧~

除了洛谷上的博客，网上搜东西，免不了看其他平台的博客，像是 CSDN、博客园之类的。但众所周知，这两个平台的内容质量一言难尽——虽然有很多优质内容，但多被抄袭注水的内容覆盖。有时候想要搜一个东西，翻开第一篇，试了下，没用，然后看下一个、下下个，以此类推，然后你可能会惊奇地发现——内容都差不多，然后你一个下午就这么过去了。

再者，CSDN 中“登录后复制代码”（都是程序员了，谁不会按`F12`查看源码啊）、“付费下载资源”（GitHub 上的免费软件拿来挂，实在不太厚道）之类的问题，对新人也不太友好。不得不感叹，国内的博客平台，环境是真的差。

这时候，看到几个炫酷的个人网站，里边有高质量的内容，还是非常让人眼前一亮的吧？后续搜东西就都认准那些个人或者小团队建设的小站，体验就好多了呢~

也就这个时候，有了对“建立自己的网站”的向往吧？

## 追忆未曾见过的黄金年代

实际上，在 2000 年左右，建立一个自己的网页，也是一种风潮呢。运用像是 FrontPage 之类的软件，就可以像编辑 Word 一样写网页，使得建站的门槛大大降低，即使是电脑小白，也能轻松写一个自己的“网络名片”呢。

不过，随着各种中心化平台的出现，以及网页的复杂化，门户网站的时代一闪而过，建站的门槛也越来越高。或许有人反驳，现在肯定有更简单的方案啊，技术总归是在进步的呢！但是，在意识层面，网站已经变成了“高大上的、难以接触的东西”，而不是“像 Office 三件套一样的东西”了。再者，有那么多写东西的平台，为何非要自己搓一个呢？

接上一句话，既然平台不作为，为什么不自己搭一个呢？

是的，就是有那么多人，搞出了多种多样的开源方案呢。虽然未见过黄金年代的荣光，但那时的余辉，又似乎处处闪耀。

## 青涩的尝试

高一时，从洛谷一篇博客中了解到 Gridea + GitHub Pages 这种超级简单的方案。虽然很多东西都不懂，但是照着文章一步步抄作业，也是第一次建立了自己的博客站呢。

不得不说 Gridea 确实是个非常纯粹、易用的方案，你真的可以像使用 Typora 那样的 Markdown 编辑器一样写文章，然后同步发布。如今如果有人想要建博客站的话，我依旧首先推荐 Gridea Pro，除了同步到 GitHub 时看脸，其他没有明显缺点。

这个小站的用途，早期是用于发各种牢骚吧？（根本没有定力认真写东西）

后来在上边同步发布我的随笔。本来想着这样语文老师的随笔作业就不用交了，结果最后老师告诉我网站上不去。哎，GitHub 的老问题了，也就只好作罢。

唯一还算有意义的文章还是[ACGN资源站一览](https://initalupotia.github.io/post/acgn-zi-yuan-zhan-yi-lan/)，不过在那以后对于这个网站也是半遗忘状态了。

现在这个站点，作为黑历史，可以通过本站的[友链](https://initalupotia.github.io/)访问哦~

## 小站缘起

本站最早可以追溯到我高三的时候，折腾了一天的新站项目吧。（旧站的确有点不堪回首啊）

当时是直接照着 B 站上一个 UP 主的方案抄作业，用的也是 Hugo + GitHub Pages 的方案。整完之后就懒得动了，后来也删库了。

不过，突然又回想起了这个东西，于是就重新弄起来啦。

### 伪Vibe Coding

高三刚开始我还很排斥使用各种 AI 工具，坚持古法使用搜索引擎。当然啦，从一大堆广告、抄袭、山寨、钓鱼网页中找到官网或者清晰明了的文档真的很有成就感的好吧？不过自从尝试把 AI 用作搜索引擎之后，就一发不可收拾，即刻沦陷。

就这么个东西用 API 实在太奢侈了，而且毕竟是后期要自定义配置的东西，至少自己得知道各部分是干什么的。所以还是让网页版 DeepSeek 写一份手册供我照抄（实际上非常感谢很多人的相关博客，数据源就是这么来的），需要什么功能再问，然后我再执行。说实在的，比之前效率高很多呢。

就拿增加 Vercount 这一项来说吧，以前可能就找另一个人的博客站，或者官网的指导文档，也能完成。但 Vercel 没有 go 环境导致 push 失败这一点我是绝对很难想到的。但 AI 提醒我看下 Vercel 的面板报错，也就快速定位错误原因了，放在以前那绝对是一下午的事。

### Connection Crisis

实际上整这个小站的一个小契机，就是我发现 HDU 校园网连接 GitHub 还挺快的呢（是我的错觉吗），于是就开工了。不过实际上，被校园网坑了几次。

首先是 clone PaperMod 的时候，网速直接掉到了 10kB/s，但是就是不断开，就很神奇。我在 Linux 环境下，不用国内源，校园网都能给出非常不错的速度来着。

本来想用大名鼎鼎的 Cloudflare Pages，顺便买个域名，然后发现 Cloudflare 被校园网屏蔽了（后来我发现，之前收藏的好多用 Cloudflare 的网站都被屏蔽了呢，一刀切，恐怖如斯）。于是选择 Vercel，不过默认的 `.vercel.app` 的域名又会被校园网屏蔽掉，那就只能去腾讯云买个个人域名替换了。不过结果来说还是好的，毕竟不到 100 块，一个好记的域名，三年，觉得价格还能接受。

唯一的顾虑可能就是资料审查和 ICP 备案，我原以为资料要审很长时间（起码几天吧），结果一个多小时就搞定了，效率这一块没得说。至于 ICP 备案，暂时用不着，也懒得弄，就这样得了。后续如果买服务器之类的再考虑。

关于速度，后来用 Vercount 统计访问的时候也发现，要加载好几秒才显示呢，不过国内网络都这样吧，通病了。

### Tools?

实际上这次最大的收获还是学会了 Git 的基本用法吧。

操作简单，差异对比详细，可以回滚，难怪有那么多人都用 Git。

另外，以后再想建站，也可以考虑 Vercel 。个人用下来觉得很不错。

## 后记

对于博客站来说，搭建只是最简单的一步啦。真正难的还是持续写下去、持续更新呢。

我见过很多运营 10 年以上的 ACGN 个人资源站，也发现收藏列表里很多个人网站都默默消失。我这个小站能运营多久呢？

至少比起资源站，我在存储上没有任何压力，免费额度完全够用；也不用考虑运营成本，现在唯一的成本也就域名吧。
