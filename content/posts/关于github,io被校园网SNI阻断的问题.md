今天闲着没事用校园网查看我那个`未麻的部屋`中 AI 发布的情况，然后发现无法访问，然后就又试了下我另一个 GitHub Pages，发现也不行。

总结下来，认为不是 DNS 劫持，而是 SNI 阻断，这就很难办了，除了自定义域名现在想不到简单的方法。

之前直接用 Vercel 的时候也经历过 SNI 劫持来着，不过毕竟是自用的博客站，所以狠下心来买个域名情有可原。但是测试用的项目我可不想这么奢侈。

这两个网站最好还是使用流量访问。

另外，突然发现 GitHub Action 的部署延迟非常离谱，设置的 20 点发布，结果是凌晨 4 点发布的，匪夷所思。而且更加恐怖的是，以 10-12 日的日记已经发布为由，没有生成？但是今天是 13 号哎？好奇怪，暂时不知道为什么。
