## 7 年前梦想的实现

既然是高通的 CPU，那么跑 Android 相比很不错吧？

当时也是这么想着，升级 Windows11，然后发现 Windows11 后来直接把安卓子系统砍掉了。而且由于 CPU 不支持虚拟化，开不了虚拟机，也不支持各路安卓模拟器软件。

既然 Windows 下走不通，那么 Linux 呢？Debian 连 MIPS 这种超小众架构都支持，那么 ARM 也不在话下吧？

然而，就算内核支持，直接安装对于 ARM 设备也是非常困难的。2023 年在视频[华为MateBook E 2019运行Linux演示](https://www.bilibili.com/video/BV1vp4y1V7tp/?spm_id_from=333.788.recommend_more_video.-1&trackid=web_related_0.router-related-2589621-ftmm5.1794663053282.175&vd_source=b332b2aaf83ea79674f90ade06bcfad8)看到了一点希望，但是这个项目没有后续。2026 年又看到视频[随手拍：华为Matebook E 2019 Linux 流畅运行Android应用（Waydroid支持）](https://www.bilibili.com/video/BV1jW8G6uExb/?spm_id_from=333.337.search-card.all.click&vd_source=b332b2aaf83ea79674f90ade06bcfad8)，突然想起了曾经没做成的事，于是就重新做了起来。

有了别人现成的[项目](https://cnb.cool/yanzhiming/planck/Planck-Workspace)，按理来说，照着手册抄作业就行了。

配置好 Fedora 虚拟机之后，按照手册上的方法构建，然后又是经典的各种报错。后来直接不干了，装了个 ZCode 直接让 Deepseek 干去了。

实际上整体过程类似于黑苹果或者安卓刷机，不过实际上这台电脑架构上确实和手机差不多来着，从芯片、接口数量、引导逻辑等都很类似。

## 从不能用到能用

内核编译好了，iso 也打包好了，剩下事情就很简单了。刷写到 U 盘中启动，然后在 U 盘的系统中刷写镜像，然后基本上就装好了。

基本功能都大差不差，但是各种细节方面还是有很多问题的。有些原有 Windows 下工作正常的硬件，在 Linux 下基本不支持。换做以前，那就凑合着用得了。不过，有 AI 的话，尝试下也未尝不可呢。

已解决的问题：

1. 后置摄像头
   对于后置摄像头的处理，绝对是 AI 在这一系列小修小补中最出彩的一环了。
   原作者本来表示后置摄像头能用，但是无法对焦。
   但是，在拿到固件以及 Windows 驱动下的各种参数后，AI 还真就调教好了对焦的步进电机。
   用 AI 也好长一段时间了，头一次见到 AI 对于硬件产生作用，真的非常有趣呢！
   一开始对于步进电机的调试还非常简单粗暴，对焦过程中甚至电机的声音都非常明显，后边才慢慢好起来的。
2. 扬声器和麦克风
3. 自动旋转
4. Type-C 视频输出
5. 视频硬解支持。

未解决的问题：

1. 前置摄像头
2. 音频播放中偶尔会出现的杂音
3. 视频输出的 4k 60Hz 支持。

## Waydroid——回归骁龙 850 的初心

在 Linux 下，使用 Waydroid 运行安卓应用程序几乎无损。终于能像安卓平板一样使用了呢。

用骁龙 850 玩《现代战舰》，全低画质下能有 20-40 fps，这个成绩已经很不错了。能玩就是胜利。

不过能感受到输入延迟还是很严重的，因此依旧不能拿来玩 OSU 之类的音游。

既然有了安卓，那么直接安装 Game Native 然后玩 Steam 上的游戏也是可行的。只不过性能上应该是比不过手机了，总觉得似乎没必要。

虽然有 Wine、Box64 之类的运行`.exe`的软件，但是觉得支持上也不理想。Galgame 就不用想了，根据我多年用安卓手机上 Winlator 的使用经验，能正常跑下来的 Galgame 寥寥无几。实际上，对于本机，使用 Waydroid 然后使用 TY 模拟器或者 ONS 模拟器才是更现实的选择。

## 折腾了半天，然后呢？

怎么说呢，觉得 Linux 生态确实比 Windows 好多了呢（而且还有安卓的加成），至少 CPU 能以相对满血的状态跑了。

明明有那么多东西想要尝试，但最近总是提不起劲。你说实用性不够吧，我手头这种小垃圾多了去了，没事总是会玩一玩的，特别是刚折腾完的时候。

写这一篇的时候明显想不出来有什么好写的。为什么呢？

毕竟大部分活都是 AI 干的啊，虽然其中的流程也大致理解，但终究不是亲手做得，总觉得没什么好说的。之前用 AI 好歹还有复制黏贴的过程，但这一次我是完全放开了，毕竟要给步进电机上多少电压之类的问题真的是我的知识盲区，这一次，我连复制黏贴都做不到了。
